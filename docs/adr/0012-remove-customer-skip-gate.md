# Customer Customize view always auto-renders, even for a Template flagged complex

[ADR-0007](./0007-skip-then-server-fallback-for-expensive-preview.md)'s skip-then-click gate — a Template estimated likely to hang the client Worker (`estimateComplexity`'s `hasExpensiveLoop`) skipped the automatic client Render and showed a "Render" call-to-action instead — is gone for the customer-facing Customize view. `CustomizeView` now always calls `useRenderMesh` with `skipAutoRender: false`; the gate itself still exists in `useRenderMesh` and is unchanged for the Admin Panel's own live preview (see ADR-0009), which keeps its explicit choice for the different reason ADR-0007 gave: an Admin iterating on raw, possibly-broken draft source doesn't want every keystroke risking a hung tab.

The gate had become actively confusing for customers rather than protective: a Template with a warmed default-preview cache ([ADR-0010](./0010-cached-default-preview.md)) renders instantly on first paint regardless of complexity — no CTA ever appears — but the moment a customer touched any Parameter, the same Template would revert to the CTA/empty state, since `forcedRef` (set only by clicking the CTA) was never true. Geometry that was visibly working a second earlier would vanish, replaced by a button demanding a click — reported as "can not render," not as a deliberate speed/cost trade-off.

ADR-0007 itself named the condition under which this mechanism could be retired: "building a Manifold-enabled openscad-wasm... deferred rather than rejected... can replace this whole mechanism later if the case for it grows." [ADR-0011](./0011-client-side-manifold-backend.md) did exactly that. The two things ADR-0007 traded the gate away to protect are both still intact without it: `useRenderMesh`'s existing `RENDER_TIMEOUT_MS` (60s) still kills a genuinely-too-slow client render and surfaces a clear message rather than hanging the tab forever, and ADR-0004's "free client compute vs. costed server compute" line is untouched — this change only ever triggers the already-free client engine, never auto-routes to a paid server Render the way the alternative ADR-0007 rejected would have.
